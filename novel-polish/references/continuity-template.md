# 连续性档案模板

阶段二生成,之后每批任务都要附带。让作者核对和修正后再使用。

## 1. 基本信息
- 书名 / 题材 / 叙事视角(第一人称、第三人称限知、全知)/ 发布形式(连载、出版)
- 总字数 / 章节数 / 分卷结构

## 2. 人物状态表

| 姓名 | 身份 | 性格关键词 | 与主角关系 | 当前所在 | 重要状态(伤势、秘密、已知信息) |
|---|---|---|---|---|---|

## 3. 人物声音卡(对白优化的依据)

每个主要人物一张:

```
姓名:
身份/教育/出身:
句长倾向:短促 / 中等 / 绵长
词汇层次:口语 / 书面 / 文白夹杂 / 行话
口头禅或标志性表达:(克制使用)
常见说话方式:爱反问 / 爱沉默 / 爱绕弯 / 直来直去 / 爱用比喻
情绪下的变化:愤怒时…… 慌张时…… 撒谎时……
对不同人的称呼与语气:对A…… 对B……
禁用词/不会说的话:
代表性对白摘录:(从原文挑 2~3 句)
```

## 4. 设定与规则表
世界观 / 能力或规则体系 / 重要物件与地点 / 专有名词写法

## 5. 时间线

| 时间节点 | 事件 | 涉及章节 |
|---|---|---|

## 6. 伏笔清单

| 伏笔 | 埋设章节 | 回收章节 | 状态(已回收/未回收) |
|---|---|---|---|

## 7. 文风样本
- 从原文摘录 3 段最能代表作者文风的文字(作者挑选更佳)
- 总结 5 条文风特征:句长、用词、修辞、视角、对话风格
- 列出作者**刻意保留**的特色(如方言、特殊句式),优化时不得抹平

## 8. 作者偏好与禁区
- 不要强行悬念 / 不要改动的段落 / 不接受的写法 / 修改力度偏好
