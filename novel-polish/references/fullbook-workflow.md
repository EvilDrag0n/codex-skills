# 全书优化模式

当用户提供整部小说或多章文本时,**不要一次性重写全文**。严格按以下阶段执行,每阶段结束后等待用户确认,再进入下一阶段。

## 为什么分阶段
输出长度有限;长文中段细节易被忽略;整本重写易造成文风漂移;一次改几百处作者无法审核。衔接、对白、心理的问题多是局部的,没必要全文重写。

## 开始前确认
- 小说总字数、章节数、分卷数
- 优化范围:仅衔接 / 仅对白 / 仅心理 / 全部
- 修改力度:L1/L2/L3
- 若超过 20 万字,按卷分批投喂,每批之间用上一批的"章节功能表"和"连续性档案"衔接

## 阶段一:全书诊断(只诊断,不改写)

### 1. 章节功能表

| 章节 | 一句话概括 | 本章功能 | 章末类型 | 章首承接 | 衔接评级 |
|---|---|---|---|---|---|

- 本章功能:铺垫 / 推进 / 高潮 / 转折 / 余波 / 过渡
- 章末类型:悬念 / 反转 / 决策 / 情绪 / 信息 / 余韵 / 泄气 / 无
- 章首承接:直接接续 / 跳时 / 视角切换 / 回避冲击 / 摘要式复述
- 评级:优 / 良 / 需优化 / 必须优化

### 2. 对白与心理扫描表(涉及时)

| 章节 | 对白问题 | 心理问题 | 严重程度 |
|---|---|---|---|

对白问题:信息倾倒 / 情绪直说 / 声音混同 / 标签堆砌 / 语体出戏 / 水对话
心理问题:告知式 / 打断节奏 / 复述对白 / 视角越界 / 空泛感慨 / 情绪突变

### 3. 全书层面的模式问题
- 章末类型分布:是否连续多章使用同一种?
- 钩子疲劳或松散的区段
- 高潮后是否有余波
- **人物声音混同**:哪些人物说话雷同?
- **口癖与重复句式**:哪些句式、词语、表情描写在全书高频重复?(如"嘴角勾起一抹弧度""倒吸一口凉气")
- **心理描写密度**:哪些章节心理过量或过少?

### 4. 问题清单(按优先级排序)
格式:
- 【高/中/低】位置:第X章第N段(或第X章末→第Y章首)
  - 类型:……
  - 表现:引用原文关键句
  - 建议:一句话

### 阶段一收尾
汇总问题总数与高优先级数量,建议分几批处理、每批包含哪些章节。**本阶段不改写任何正文。**

## 阶段二:连续性档案

按 `references/continuity-template.md` 输出,包含:人物状态表、**人物声音卡**、设定表、时间线、伏笔清单、文风样本(3 段原文 + 5 条文风特征)。
让用户确认并修正后,再进入阶段三。

## 阶段三:分批精修

### 每批输入
连续性档案 + 本批要处理的位置(章末/章首接缝,或具体对白、心理段落)

### 每处输出格式
- 位置:第X章第N段
- 诊断:……
- 修改前:……
- 修改后:……(关键处给 2 个方案)
- 说明:……
- 【新增】标注:……
- 连续性提醒:……

### 约束
- 衔接问题:只改接缝;章末不超过最后 500 字,章首不超过前 500 字,除非用户许可。
- 对白、心理问题:只改有问题的句段,不动其余正文。
- 评级"优/良"的位置直接标注"无需修改"。
- 修改必须符合文风样本和人物声音卡。
- 每批建议 5~10 处,方便作者审核。

## 阶段四:卷末与卷首专项
每卷单独处理:
- 卷末:主线收束 / 情感落点 / 新钩子 / 是否需尾声,给 2~3 个方案
- 卷首:时间锚定 / 处境重建 / 新鲜感 / 核心问题,给 2~3 个方案
- 卷末与卷首的呼应检查

## 阶段五:终检
- 修改后的章末钩子,下一章是否有回应?
- 新增细节与前后文是否矛盾?
- 人物状态、时间线是否连贯?
- 对白修改后,人物声音是否仍然一致?
- 心理修改后,情绪弧线是否仍连贯?
- 章末类型分布是否比原稿更均衡?
- 输出"残留风险清单"和"建议作者人工复核的位置"。

## 全局禁忌
- 禁止一次性输出全书改写稿。
- 禁止在阶段一直接修改正文。
- 禁止为制造钩子或"升华"而改变剧情、关系、设定。
- 禁止为了统一风格而抹平人物之间的声音差异。
- 上下文过长无法确认细节时,明确告知,请用户提供对应章节。

## 阶段一输出示例

| 章节 | 一句话概括 | 本章功能 | 章末类型 | 章首承接 | 衔接评级 |
|---|---|---|---|---|---|
| 第11章 | 林岚发现地下室有人 | 高潮 | 悬念 | 直接接续 | 优 |
| 第12章 | 林岚次日回忆昨夜 | 过渡 | 泄气 | 回避冲击 | 必须优化 |
| 第13章 | 苏瑶赶往北境 | 推进 | 无 | 视角切换(未锚定) | 需优化 |

- 【高】位置:第11章末→第12章首
  - 类型:回避冲击、摘要式复述
  - 表现:"第二天早上,林岚醒来,想起昨天……"
  - 建议:改为直接接续,先写两人对峙
- 【中】位置:第12章末→第13章首
  - 类型:章末泄气、视角切换无锚点
  - 表现:"她躺下睡了"→"苏瑶翻身上马"
  - 建议:章末补具体悬念,章首首句锚定时间地点
