## 先做四个人

总纲之前先把四个人想到像活人的程度，主角，第一配角，感情线上的那个人，最终的对手。

想到什么程度算够。知道他喜欢什么颜色、有什么小癖好、口头常挂什么话，这些大多用不进正文，它们的用处是让你在任何一场戏里都知道他会怎么反应。

其余的人物等总纲出来以后，按主线的需要补。也可以反过来，心里先有一个很有样子的人，再为他设计情节。

## 人物卡写什么

思想决定性格，性格决定命运。人物卡从他怎么想写起，外在的东西往后放。

| 栏目 | 写什么 |
|---|---|
| 想要的 | 他自己说得出口的目标 |
| 缺的 | 他自己没意识到、故事会逼他面对的东西 |
| 信的 | 一条他会照着做的处世道理。要清晰，要突出 |
| 过人之处 | 只写一样 |
| 缺陷 | 他总在哪一步犯同一个错 |
| 怕的 | 具体的一件事或一个人 |
| 在谁面前退让 | 一条 |
| 为什么撒谎 | 一条 |
| 秘密和知情范围 | 他瞒着谁什么，他不知道什么 |
| 好恶和习惯 | 喜欢什么，讨厌什么，一个常做的动作 |
| 记号 | 一处长相，或一件随身的东西，或一个外号 |
| 说话方式 | 句子长短，怎么称呼人，急了会怎样 |
| 处境 | 出身、年龄、位置、手里有什么、欠着谁 |
| 关系 | 和其他主要人物各是什么关系，会怎么变。感情线上的人另写一句，她看上他的什么，他看上她的什么 |
| 弧线 | 开头是什么样，哪件事让他变，最后是什么样 |
| 对主线的用处 | 没有他，哪一段故事讲不下去 |

模板里的核心人物卡就是这十六栏。其他主要人物用简卡，只留想要的、缺陷、记号、说话方式、知情范围和对主线的用处。

出身和运气不归思想管。作者可以给人物有利或不利的环境，时势也造人。

年龄写清对应的故事时间。没有设定生日就不补造，写“约十六岁”。

## 主角

主角凭什么是主角。他要有一样特殊的才能或者一份特殊的本钱，再加一个强到能当符号的个性。个性一立，奇遇和挫折都顺着它安排，读者猜得到的情节不丢人，要紧的是情理之中。

不写完美的主角。英俊、富有、聪明、武力都给他，他就没有可写的难处，也没有可信的位置。给他一样过人之处，其余平常，把这一样用到极处。

聪明要靠事情证明。写智谋型的主角难，难在作者得真替他想出办法。

让主角守着一个只有读者知道的秘密。别人只能猜，猜不着或者猜错。不要为了显得坦诚让他轻易把秘密告诉亲近的人，现实里没有人这样做。

读者把自己放进主角，有两条路。主角的处境和读者相近，或者主角是读者想成为的人。平凡不等于有代入感，读者倾慕的人一样能代入。

## 配角的七种用处

每个配角都有他的用处，也都衬着主角。

| 倾向 | 类型 | 用处 |
|---|---|---|
| 正面 | 同伴 | 和主角共进退 |
| 正面 | 导师 | 给主角正确的本事和见识 |
| 正面 | 心上人 | 影响主角的心境，常常左右全局 |
| 不定 | 神秘人 | 对主角有明显的好处或坏处，不报来历 |
| 不定 | 竞争者 | 起步比主角高，忌惮或欣赏主角的潜力，逼着主角成长 |
| 不定 | 丑角 | 帮倒忙，带来笑料 |
| 负面 | 陷害者 | 为了主角手里的东西，或者单纯看不顺眼，一直作对 |

一个人物可以兼两种，也可以半路换类型。

双方力量要不断地平衡再打破。正面太强，读者不替主角担心。负面太强又没有转机，主角的位置就垮了。

配角分两种。一种推着主线走，一种只是添彩。添彩的人物哪怕只出场一次，也要让人记得住。

不管哪一种，配角都有自己眼下要办的事。

## 对手

对手要有他自己的道理，站在他的位置上看，他做的事说得通。人本来就矛盾，没有纯粹的善，也没有纯粹的恶。

对手的强度由力量阶梯和地图管着，见 `references/world.md`。

掌权的对手要像掌权的人。在乱世里站起来的人多半心硬、有手段、戴着面具，公私分明。把他写得心软又任性，手下凭什么服他。

最终的对手早一点露面，哪怕只是一个名字、一个背影。

## 朋友、感情和亲人

朋友是和主角真正平等的人，地位和本事相近。朋友、对手、敌人这几种关系可以来回变，关系一固定就难写，要么写死，要么沦为跟班。朋友要有自己的戏，自己的一条线，不只围着主角。

感情要有理由。她看上他的什么，这个理由决定她后面的所有举动。好感多半是长期相处攒出来的，是对一个人的性情和为人了解以后的事。看一眼就死心塌地，读者不信。

和主角有感情张力的人物不止一个时，每一个都要不一样，各有自己的日子要过，各有脾气。把一群人写得毫无妒意、和睦共处，就不是人了。主角心里最重的那一个最好只有一个。感情戏写得少而准。

亲情写它被什么拧着。父子、兄弟之间的对立能撑起很重的戏，这种对立必须有道理，而且晚辈对长辈的恨多半只是牵着戏走的一根绳，真到了那一步是下不去手的。

## 让读者记住

读者的记性有限，一个人物只能被记住一两样东西。特征只抓一处，泛写等于没有。

几种加深印象的办法。

- 外号。别人怎么叫他，骂他的时候揪着什么不放。
- 自报家门。他怎么介绍自己。
- 随身的东西。一把扇子，一件旧衣服，一样兵器。
- 一句只有他会说的话，一个只有他会做的动作。

重要的个性在不同的事情上反复出现。

只出场一次的人不起名字，用身份称呼，掌柜、执事、他二叔。名字后面第一次跟上身份，帮读者认人。叙述里不用小什么、阿什么这类昵称代替正式的称呼，昵称留给人物之间叫。

## 每个人说话不一样

声音的差别来自身份、关系和眼下的压力。同一个人对上级、对下属、对喜欢的人，说话不是一个样。

给每个主要人物写两三句他会说的话，再写一句他绝不会说的话。把两个人的台词对调，读着别扭，就对了。

口头禅少用。一个人每次开口都带同一句，是在演这个人物。

人物说的话要合他的年代和出身。那个年代的人嘴里会带上那个年代的流行话，读者一听就信他活在那时候。

## 人物弧线和功能

主要人物在全书里要变。写清变化的起点、逼他变的那几件事和终点。变化落在选择上，他后来做了一件开头绝不会做的事。

每一卷给主角一小段弧线，和这一卷的冲突绑在一起。

活跃的人物不要太多。同一段故事里常出场的控制在五六个以内，其余的出场时带着身份提醒读者。
