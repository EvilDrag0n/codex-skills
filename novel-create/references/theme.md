## 先看用户给了什么

| 手里有的 | 做法 |
|---|---|
| 什么都没有，或只说了题材 | 给三个方向不同的候选。每个写一句话故事、主卖点和最大的风险，标出推荐的一个，然后按推荐项往下做。用户另选再换 |
| 一句灵感或一个设定，包括题材加一个主角、一种职业 | 先判断它是下面三种创意里的哪一种，再把它补成架构型 |
| 一个人物或一段关系 | 从这个人想要什么、缺什么倒推冲突，再给他找一个合适的世界 |
| 已经想得比较完整 | 不重新发明。按本文件的清单查缺口，只补缺的 |

三个候选要真的不同，换的是处境和冲突，不能只换题材的皮。候选写在 `设定/主题与卖点.md` 的候选方向一节里，每个三四句话就够，选中的那一个再往下展开。

用户说直接写、别问的时候不停下来等他选。自己挑最有把握的一个往下做，另外两个各留一句话在候选方向一节里，交付时提一句还有哪两条路。

## 创意分三种

点型创意是一句有趣的对白、一个动作、一个小设定。它能点缀，撑不起故事。记进素材，以后变成某个人物的习惯或口头禅，不进骨架。

关键型创意是一个转折，或者一个出人意料的局。它够撑一个单元或一卷的高潮。开篇也需要一个关键型创意，读者在前几章决定走不走。

架构型创意是一个能不断生出新冲突的处境。长篇靠它。几个关键型创意挂在一个架构型创意上，就是一本书的骨架。

检验手里的创意够不够架构型，问三句。

1. 主角达成一次目标以后，这个处境会不会自己给出下一个目标。
2. 能不能换场地、换对手、抬高代价，而故事还是这个故事。
3. 一句话讲给不认识的人听，他会不会追问然后呢。

三句里有一句答不上，就继续补，或者把它降为关键型，另找架构。

## 一句话故事

写成这样一句。谁，带着什么特殊的处境或者唯一的长处，想得到什么，被什么挡着，输了会失去什么。

五个位置都要填实。“一个少年踏上了变强之路”只填了第一个位置。

## 主题写成一个问题

主题不写成口号。写成一个两头都有道理的问题，例如，是强大的力量带来了战争，还是要守住和平才需要力量。这本书用主角一次次的选择和代价去回答它。

能留住读者的落点在人性上。画面、设定和文笔吸引读者看第一眼，让他追几百章的是人在压力底下怎么选。定主题的时候同时写下，这本书最想让读者在哪里哭、在哪里笑。

正文里没有人替作者把主题说出来。小说不必非得教给读者一个道理，道理留给读者自己悟。

## 读者持续得到什么

很多创作是在满足人在现实里够不着的愿望。写清这本书持续给读者的满足是哪一两样，变强、翻身、守护、解谜、被偏爱、智斗、经营积累，都可以。再写清它多久兑现一次。

下面七样是长篇网文常用的料，对照着看这本书哪几样是主菜，哪几样只是配菜，哪几样不要。

| 元素 | 要点 |
|---|---|
| 有个性的主角 | 个性强到能当符号。挫折顺着他的性格来，不为了挫折而挫折 |
| 成长 | 武力、财富、官职、名望都算。难处在速度和节奏 |
| 阶段性成就感 | 长了本事要有地方用，钱要花出去才有感觉 |
| 感情线 | 惜墨。真正放在心上的最好只有一个 |
| 关系张力 | 人物之间的吸引和拉扯可以铺开写，每个人要不一样，各有自己的日子 |
| 友情 | 朋友得是和主角平等的人，关系会变，有自己的戏 |
| 亲情 | 天然的感情最难写，拧着写才出彩 |

## 题材与读者

先选写得动的，再看市场。对一个题材有积累，细节才立得住，读者感到的真实感一多半来自细节。太冷的题材要掂量，热到人人都在写的题材也要掂量。

可以一个主题材加一两种调味，比如都市加悬疑。调味要能一直供得上。没有把握写得好笑，就不把幽默当卖点。

写清读者是谁，年龄层、偏好、在哪个平台看。这决定尺度、节奏、用词和章均字数。给中学生看和给三十岁的上班族看，同一个爽点的写法不一样。

故事依赖真实的历史、城市、职业、法律或技术时，在这里列出要核准的部分。查不查、查不了怎么标，按 SKILL.md 的“现实部分的核准”办。

## 同中求异

没被写过的题材已经很少。找出同类里成功作品的骨架，弄清读者在那里要的是什么，把这个留下，再换掉一块。

换的办法有四种。

- 组合。把两种现成的题材元素接在一起。
- 逆向。这个题材里人人默认成立的一条，把它反过来。
- 趋势。往还没普及的技术和生活方式里找，离现在越远，想象的余地越大。
- 换角度。同一件事换一个通常不当主角的人来看。

只借骨架。不用现成作品的人物名、设定名和情节。

## 立意管着下游

主题定了，后面三样跟着受约束，写进文件里，给故事世界和大纲那两段用。

- 主角的气质决定世界的风格。行侠仗义的主角，世界就带着中国式的江湖底色。讲规矩重体面的主角，世界偏向另一种秩序。
- 立意决定力量的上限。想写热血仗义，上限就不能高到主角抬手灭世，高到那个程度读者代入不了仗义。想写登临绝顶、俯视众生，上限就不能只到拳脚功夫。
- 立意决定金手指的样子。宁折不弯的主角，金手指可以是招祸的宝物，怀璧其罪。算计型的主角，配一个搜集情报的能力。低调的主角，配藏身换貌的本事。

## 基调、结局方向、书名和简介

基调用一两个词定下来，再写一句这本书的叙述口气像什么人在讲。人称和视角在这里定，没有特别理由就用第三人称贴近主角。

结局现在只定方向，细节留到大纲。可选的收法见 `references/outline.md`。方向要能回答前面那个主题问题。

书名最后取。从已经定实的东西里找，主角的处境、那件关键的东西、那个地方。

简介写两版。一版三百到五百字，给自己和大纲用，把主线讲明白。一版一两百字，给读者看，只讲主角的处境和眼前的麻烦，留一个问题，不剧透结局。

## 割爱

好点子太多，全挤进一本书，读者会麻，主题会散。能给主线加分的留下。接不上主线的存起来，留给下一本。

想不出点子时回到原点，重看一句话故事和人物想要什么，再看已经定下的内容里有哪一处没交代完、可以往外延伸。

## 完成的样子

`设定/主题与卖点.md` 里至少有这些，模板在 `assets/templates/主题与卖点.md`。

- 题材、读者、篇幅和章均字数。
- 一句话故事，五个位置都填实。
- 主题问题，以及全书结局大致怎样回答它。
- 架构型创意，和它通过三问的理由。
- 主满足点和兑现的频率。
- 同类作品的骨架和这本书换掉的那一块。
- 对世界风格、力量上限和金手指的约束。
- 基调、人称、结局方向。
- 暂定书名和两版简介。
- 候选方向，选中的和没选的。

哪些是用户定的、哪些是暂定，写在 `项目说明.md` 里。主题这一段做完就把 `项目说明.md` 建起来，模板在 `assets/templates/项目说明.md`。
