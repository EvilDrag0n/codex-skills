# 活人感小说写作技巧

写正文前读这一份。它把 human-writing 的小说规则和十四份网文技巧文档合在一起，只留会改变成稿的部分。

活人感在小说里落在三处。人物在办他自己的事，叙述站在某个人的位置上看，句子是平常的中文。口头禅、粗口和网络梗给不了活人感，堆细节也给不了。

## 人物先有一件眼下要办的事

进入任何一场戏之前，先知道五件事。谁先受到影响，他此刻想得到什么，为什么今天必须动，什么让老办法不灵了，这次行动会留下什么后果。

不必每场都是生死。要回一笔钱，躲开一次见面，保住体面，让家里人信一句话，都能推着戏走。

配角也有眼下要办的事。只负责递消息、制造误会、夸主角或者被主角打脸的人，两三章以后读者就看出他是工具。给他一件和主角无关的小事，他就立起来了。

## 性格写在选择和代价里

不给人物贴善良、聪明、冷漠的标签。写他在谁面前会退让，碰到什么会撒谎，擅长解决哪种问题，又总在哪一步犯同一个错。

聪明要靠事情证明。说他智商多高没有用，让他看出别人没看出的一处，再让这一处在后面应验。威望也一样，没有人见一面就折服，手下服他是因为他做过的事和他身后的实力。

主角不能完美。英俊、富有、聪明、能打一起给，读者就找不到他的位置。只给一样过人之处，其余和普通人一样，一样东西用到极处比十项全能好看。拿掉金手指，他身上还得剩下让人愿意跟的品质。

好人不必处处对，对手也有他的道理。把好坏写在脸上，人物就成了脸谱。

重要的个性要在不同的事上重复出现。读者记人靠的是重复，一次亮相记不住。

## 每场戏改变一点东西

进场时知道双方各想得到什么。出场时，信息、关系、计划、风险、权力、理解、情绪这几样里至少有一样和进场时不同。

一场戏里只有环境、寒暄和设定说明，没有人换办法，这场戏就压成两三句概述，或者删掉。

转折尽量从人物先前的行动、已有的关系和早就立下的规则里来。意料之外要落在情理之中。车祸、绝症、突然冒出来的高人和临时添的新规则不能反复救场。偶然可以开头，不能收尾。

有得必有失。主角拿到一样东西，就该付出一样东西，时间、伤、欠下的人情、得罪的人都算。只进不出，读者很快就不信了。

## 对白在做事

人物开口通常是在试探、遮掩、说服、拖延、靠近、推开或者保住面子。先定下这一场里每个人想从对方那里拿到什么，台词就有了方向。

两个人都知道的事，不会为了读者再念一遍。人物也不轮流替作者讲主题。

这样写不行。

> “你知道的，我们周家三代经商，到父亲这一辈才在青州站稳，如今父亲过世，这笔债我一定会还。”

这样写可以。

> “钱呢？”
>
> “下个月。”
>
> “上个月你也说下个月。”
>
> 周启明把茶杯转了半圈，杯把朝着自己。“老三，我爹的丧事才办完。”
>
> “我知道，我随了二百。”
>
> 没人再说话。灶上的水开了，壶盖一下一下地跳，周启明没去提。

后一段里没有人介绍周家的生意，读者照样知道有债、有丧事、有交情，也知道这交情只值二百。

对白里的张力有三级，心里较劲，嘴上交锋，动手。不必每次都走到第三级，停在第一级的戏常常更紧。越生气越安静的人，把周围人的话写快写碎，他的沉默就显出来了。

人物可以答非所问，可以只说一半。不同人的声音来自身份、关系和眼下的压力，不靠给每人配一句固定口头禅。

对白场景宜短。张力起来，冲到顶，尽快落下。

## 动作带着态度

点头、耸肩、叹气、看了一眼、站起来、走出去，这些动作只说明人物还活着。一个动作要连着他的意图、态度或处境才算数。

这样写不行。

> 他点了点头，叹了口气，看了她一眼，转身走了出去。

这样写可以。

> 他把钥匙放在鞋柜上，放得很轻，没让它碰出声。门也是带上的，没有摔。

改的时候对白可以一字不动，只换动作。同一句“我们很快就能查清楚”，说话的人是拍着同事的肩说，还是盯着抽屉说，是两场戏。

## 细节跟着视角走

紧张的人先找出口。等钱的人留意手机有没有亮。心虚的人记得对方沉默了多久。一个细节同时交代了东西和看东西的人，才值得留下。

近距离视角只写这个人当时能知道的事。全知视角可以移动，每次移动要让读者知道现在跟着谁。

### 外貌只抓一到两处

把肤色、眉、眼、鼻、唇、腰、衣料、佩饰从头排到脚，读者一样也记不住。泛写特征等于没有特征。

这样写不行。

> 她肤如凝脂，眉如远山，一双秋水般的眸子顾盼生辉，琼鼻樱唇，当真是倾国倾城。

这样写可以。

> 她进门的时候，账房正在数铜钱，数到四十七抬了一下头，后面的数就忘了。
>
> 沈砚没看她的脸。他先看见的是鞋，鞋帮上糊着一圈黄泥，城里只有南渡口有这种泥。

后一段没有一个形容美貌的词。账房忘了数，读者知道她好看。沈砚盯着鞋，读者知道沈砚是什么人。

给主要人物一个能认出来的记号就够，一处长相、一件随身的东西、一个别人叫他的外号。记号要重复出现。服饰可以写，写到能说明身份、处境或年代为止。

### 环境抓关键的一角

环境描写在四种时候上场。要衬出这场戏的情绪，要让读者知道人在哪里，场景换了，或者地形陈设马上要被人物用上。四样都不沾，就不写。

写景不求全。集市抓闹，锅炉房抓热，悬崖边抓怕，垃圾场抓臭。眼、耳、鼻、舌、身、心六路里挑最要紧的一两路，勉强凑齐六路会变成清单。

用读者见过的东西去比。说一艘船长二十里，没人有感觉。说它的影子盖住了半座城，城西的人那几天没见过太阳，读者就知道它多大了。

世界的基调在开头几段就要定下，轻松、阴冷还是肃杀，靠选什么词、看见什么东西来定，不靠一句“气氛很压抑”。

## 心理写动作托不住的那一层

动作已经把情绪写出来，就不再翻译。人物把门打开又关上，后面不需要“他犹豫了”。

只删重复的翻译，心理本身照样要写。人物心里在算哪笔账，怕的是哪件事，忽然想起了谁，把对方看错在哪里，想做又没做的是什么，这些只能从他心里知道。

> 借，还是不借。三万块她拿得出来，拿出来以后，女儿下学期的钢琴课就得停。表哥上回借的八千到现在没提过。可他在电话里没说钱的事，只问了一句姑妈的坟今年谁去上的。她握着手机，想起小时候发烧，是表哥背着她走了四里地。

这一段没有“她很纠结”。读者看见她在算什么。

长篇里每个关键选择的前后，读者都应当知道人物在权衡什么。连着几章只有动作和对白，人物就成了被情节推着走的木偶。

神态写看得见的脸和身体。嘴角往下压了一下，手指在杯沿上停住，眼睛一直没往他那边看。“神情复杂”“脸色难看”只给了结论。

## 设定等人物碰到再讲

先问一条规则会改变谁的行动，谁得利，谁付代价。人物还没碰到它，正文就不用提前介绍。

交代设定有三层手法。最差是列表，把等级和数值排出来。中间是陈述，用一段话说精灵住在森林里、身手敏捷。最好是让人物撞上去，他的箭射不中她，她在树枝间比他在平地上还快。

这样写不行。

> 天玄大陆的修炼分为九个境界，每个境界又分九层。青云宗是东域三大宗门之一，外门弟子三千，内门弟子三百。林尘今年十六岁，入门四年，修为停在炼体三层，是公认的废材。

这样写可以。

> 测灵石亮到第三格就不动了。
>
> 执事没抬头，在名册上勾了一笔，喊下一个。后面的人往前挤，有人的肩膀撞在林尘背上，没道歉。
>
> 他把手从石头上拿下来，掌心还是凉的。外门十六岁往上的弟子里，停在三格的只剩两个人，另一个是伙房挑水的老吴。

后一段里读者知道了有等级、三格很低、他在这里没有地位，没有一句是在介绍。

陌生名词一次少来几个。先让读者看见一样东西怎么用，再给它名字和来历。规则可以被人物误解，作者不能在需要救场时改掉。神秘的东西留一部分不解释，解释尽了就不神秘了。

## 情绪靠铺垫兑现

读者的痛快和难过都要先存后取。一个爽点有四拍。先让读者知道主角要什么、差多少。再压，让他被看轻、被堵住，压的时间和后面爆发的力度相称。然后兑现，办法要用到前面给过的东西。最后写在场的人是什么反应，谁服了，谁怕了，谁从此记恨。少了第四拍，成长就是锦衣夜行。

压不等于虐。读者能忍主角受挫，不能忍他窝囊。受挫时他得在想办法。

谜底的时机像拉鱼竿。读者还没开始想知道就揭开，没有分量。拖到读者已经不关心才揭，也没有分量。读者最想知道的答案不早给，每过一段透一点。

高潮不在多。把积蓄的东西放在主线的关口上一次用足，比处处小高潮有力。连着高潮读者会麻，该收就收。

## 章末停在后果上

一章可以停在一个已经做完、撤不回的动作上，一段关系的新位置上，一样旧东西的新含义上，或者一个刚刚露出来、读者还来不及弄清的事实上。

这样写不行。

> 林尘握紧了拳头。他不知道的是，一场更大的风暴正在等着他。

这样写可以。

> 名册翻到最后一页。他的名字还在，上面多了一道朱笔，从左划到右。

前一种是叙述者跳出来预告，什么也没有发生。后一种事情已经发生了，读者要翻下一章才知道那道朱笔是什么意思。

不必每章都悬着。大事落定以后，停在一件安静的小事上，读者反而记得住。不要在章末替读者总结这一章的意义，也不要用“突然”“就在这时”硬造一个钩子。

## 句子是平常的中文

网络小说对文字只有一个要求，读者能毫无障碍地一口气读下去。读者停下来琢磨一个词是什么意思，就从故事里掉出来一次。

- 先说谁做了什么，再补时间、原因和条件。一句话里有三四个“的”，把做事的人提到前面重写。
- 选直白的词。能说“买”不说“购买”，能说“改了”不说“进行了修改”。华丽的辞藻让读者去看字，不看故事。
- 长短句要有落差。十个字的句子可以挨着四十个字的句子，长短跟着事情的密度走。打斗和追逃用短句，回忆和权衡可以放开写长。
- 连词删一半。“因为”“所以”“但是”“同时”“然而”，中文小句靠语序和事理自己会接。
- 该重复就重复。主角的名字、一件东西的叫法，前后用同一个。第二次换成“这名少年”，第三次换成“这位年轻的修士”，文章就油了。
- 分段照顾手机上的读者。一段一般一到四句，对白独立成段。全章都是一句一段也不行，那是在敲鼓点。
- 用词不出戏。古代背景里出现“信息”“智商”“效率”，读者会跳出来。有些词古已有之，读者却认它是现代词，比如“新闻”“文化”，一样会跳，照读者的感觉来，不照词典来。
- 写一个画面之前先在心里看见它。雨多大，从谁的背后看，两个人什么关系，路面是干是滑。看见了再写，写出来的是这一场雨，没看见就写，写出来的是所有的雨。
- 比喻一段里至多一个，落下以后不解释。本义已经清楚就不用比喻。

## 成稿硬禁令

下面八项出现在叙述里就不能交稿。它们是模型最顺手的姿势，读者一眼能认出来。禁的是修辞动作，换一套字做同一个动作也算。

检查脚本能自动拦住其中的翻案腔、破折号、提示性冒号、硬停词和路标。排比、抽象抒情和章末升华它只能提醒，认不全，改稿时自己查。

- 翻案腔。先立一个读者并没有的误解，再推翻它来抬价。常见的样子有“不是……而是……”、“并非……而是……”、“没有因……便……”、“不仅……更……”、“不在于……而在于……”、“与其说……不如说……”、“看似……实则……”、“表面……其实……”、“你以为……其实……”。判断从正面下。
- 三项以上的同构排比。两项为限，第三项换一种说法或者删掉。
- 给抽象名词配具体动词的抒情。时间不会保管什么，岁月不会磨平什么，沉默不会发芽。写具体的东西时不受影响。
- 破折号和连接号。话被打断，用省略号，或者让对方的话、一个动作直接切进来。
- 提示性冒号。冒号只用来引出人物的原话。系统面板、书信和告示这类文内文本放进引用块或【】里，按它本来的格式写。
- “说白了”“说穿了”“先说结论”。
- “值得注意的是”“需要指出的是”“从某种意义上说”“更微妙的是”“总而言之”“综上所述”“不仅……更是一种……的体现”这类路标。
- 章末或卷末的升华。事情讲完就停，不把一章的意义再说一遍，不升到命运、时代和所有人。

人物对白按人物处理。一个爱讲道理的角色嘴里说出“我不是怕他，而是怕他背后的人”，是他的说话习惯，可以留。同一种句式从好几个人嘴里说出来，就是作者的习惯漏进去了，要改。

## 小说里的模型套语

下面这些不是禁词，单独出现一次没有问题。它们的毛病在于谁都能用、哪里都能放，一章里同一类出现三次以上，就挑出来换成只属于这个人、这一刻的写法，或者直接删掉。

| 类别 | 常见的样子 |
|---|---|
| 表情 | 嘴角勾起一抹弧度、嘴角微微上扬、眼中闪过一丝什么、眼底掠过、瞳孔骤缩、眉头微蹙、眸色一沉 |
| 身体反应 | 深吸一口气、倒吸一口凉气、心头一震、心中一凛、浑身一僵、指节泛白、喉结滚动、呼吸一滞 |
| 气氛 | 空气仿佛凝固、时间仿佛静止、气氛降到冰点、死一般的寂静、落针可闻 |
| 抽象情绪 | 五味杂陈、说不清道不明、莫名的情绪、难以言喻、一股暖流涌上心头、感到一阵什么 |
| 叙述腔 | 这一刻他终于明白、他不知道的是、殊不知、命运的齿轮、一切才刚刚开始、从今往后 |
| 声音 | 低沉而富有磁性、带着不容置疑的语气、一字一顿、声音不大却清清楚楚 |
| 模糊词 | 似乎、仿佛、宛如、某种、一丝、一抹、一股，密到每段都有 |
| 说话方式 | 冷冷地说、淡淡地道、缓缓开口、沉声道，一章里排着出现 |
| 廉价转折 | 突然、忽然、就在这时、没想到、下一秒，密到每页都有 |

换的办法只有一个，回到这个人物此刻的处境里，问他会注意到什么、身体哪里先有反应、手里正拿着什么。

## 最后冷读

暂时忘掉所有规则，只回答下面五句。

哪里让我相信这个人真的在乎这件事。

哪里让我想翻下一页。

哪一段像人在处理一个难处，哪一段像模型在完成写作任务。

哪句话说得比这场戏大。

这一章在哪一句已经结束了。
