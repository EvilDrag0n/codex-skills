# 大纲

这一段的产出是 `大纲/全书总纲.md` 和 `大纲/第N卷章纲.md`。大纲的用处有两个，写的时候不迷路，几百章以后不忘事。

一本百万字的书，大纲不过几万字，花在这几万字上的力气却比写同样字数的正文多得多。没有大纲的长篇常见的下场是虎头蛇尾、前后矛盾、挖了坑填不上。

大纲也不宜写死。主线清楚、人物清楚就可以动笔，细处留给写的时候。写长篇要很多天，每天的状态不同，后面随时会冒出更好的想法，别让大纲把它挡在外面。

## 大纲的层级

| 层 | 篇幅 | 内容 |
|---|---|---|
| 总纲 | 一两页 | 一句话故事、主线、结局方向、分卷表、主要伏笔 |
| 分卷纲 | 每卷五百字左右 | 这一卷的地图、目标、对手、高潮、收获和代价、交给下一卷的问题 |
| 章纲 | 每章一句到一段 | 这一章谁要什么、什么挡着、怎么转、章末停在哪里 |
| 场景表 | 写之前在心里排 | 见 `references/drafting.md`，不落盘 |

总纲和所有卷的分卷纲都写在 `大纲/全书总纲.md` 里。章纲写在 `大纲/第N卷章纲.md` 里，只给眼前要写的那一卷建这个文件。

章纲不必一次写完全书，也不必一次写完一卷。写到哪里补到哪里，一次补五到十章。还没轮到的卷不建章纲文件。

## 做大纲的顺序

1. 读 `设定/主题与卖点.md`、`设定/人物设定.md` 和 `设定/故事世界.md`。缺哪一份，按 SKILL.md 的办法补一个最小版本。
2. 定成长的阶梯。主角从哪里起步，最后到哪里，中间分几档，见 `references/world.md`。
3. 写主线。
4. 分卷，每卷写五百字左右，像给一部电影写内容简介。
5. 顺着分卷回头补人物和世界，把这一卷用得上的补细。
6. 把眼前要写的那一卷细化成章纲。
7. 做最后的检查，排伏笔、呼应和悬念。

## 主线

主线是全书的中心事件。长篇的主线通常是两三股拧在一起。

| 股 | 问的是 | 例 |
|---|---|---|
| 成长线 | 主角怎样一步步变强 | 功夫练成，生意做大，官做到头 |
| 矛盾线 | 主角和最大的对手怎样了结 | 报仇，夺位，破案 |
| 关系线 | 主角和最要紧的人怎样走到最后 | 感情，师徒，兄弟 |

主线不宜超过三股。几股线在高潮或结尾处交汇。

一条好的主线让人感兴趣，有新鲜的地方，能在精神上引起共鸣。同是穿越回古代，拿着枪去杀人只是胡闹，去揭开一桩千年的谜就高出一截。

每股主线拆成几个阶段，一个阶段是一段完整的小故事。阶段之间要有转折，一波三折。找仇人，找到了，发现找错了并且因此害了最亲的人，真仇人现身，原来真仇人也是被人利用的，这样才撑得起几十万字。

总纲里有一张主线对照表，把每股主线的每个阶段和出场人物、时间、地点、对应的卷对起来。查一个人物，就能找到他在哪里、什么时候出场。

## 一个故事单元的四个阶段

全书、一卷、一个单元都可以用这四个阶段来问。

故事发生。

- 事情是怎么引起的，从谁开始。
- 主角为什么卷进去。是他好奇主动去查，还是被逼得不得不走这条路。
- 这里埋了什么伏笔，留了什么悬念。

发展和阻力。

- 要解决问题或者达到目标，需要做什么，需要哪些条件。
- 凑条件的时候遇到什么阻力，主角怎么对付的。
- 和哪些人打了交道。
- 对手出来没有，怎么和主角碰上的。

高潮。

- 小的阻力过去以后，最大的那一个是什么。
- 对手是谁，有多强。
- 用什么办法解决最痛快。
- 各个人物受到什么冲击。主角让谁震动了，是朋友、对手还是旁观的人。

结尾和新的开端。

- 主角变了什么，得到什么，精神上的还是物质上的。
- 其他人怎么样了，和开头对比。
- 这一段结束是不是另一段的开头，引出了什么新的悬念。

## 冲突从哪里来

| 来源 | 说明 |
|---|---|
| 主角看重的人 | 亲人、朋友、心上人、恩人受到威胁或被人觊觎 |
| 主角的归属 | 家族、门派、家乡、国家受到侵犯 |
| 群体之间 | 不同族群、阵营、阶层之间的对立 |
| 是非 | 主角看不下去的事。主角做了出格的事，要给出读者认的理由 |
| 自身的需要 | 主角要活命、要变强、要一样东西，这样东西在别人手里 |

五种来源可以叠。最有力的冲突是主角自己的需要和他看重的人撞在一起。

别让女性角色只当被抢的东西。她受到威胁的时候，她自己在做什么，要写。

冲突要升级。同一种冲突用第二次，代价要更高，或者换一个层面。

## 分卷

最顺手的切法是按地图切，主角活动的范围变一次算一卷。玄幻、仙侠换的是地界，竞技文换的是队伍，官场文换的是任职的地方，都市和悬疑受地点的影响小一些，可以按案子、按阶段切。有把握以后也可以按时间、按人物、按一件贯穿的东西来切。

每卷的分卷纲写这些。

- 这一卷在哪里，主角进来时什么处境。
- 这一卷的目标，最大的对手。
- 中间的两三个转折。
- 高潮怎么打，用到前面的什么。
- 主角得到什么，付出什么，这一卷里他变了什么。
- 为什么离开，交给下一卷的问题是什么。这一条要在本卷结束之前就铺垫好。

按地图切的时候时间容易乱。另列一张年表，记下每一卷开始和结束时的故事时间，以及主要人物那时的年龄。

估一下篇幅。总字数除以章均字数是总章数，再分到各卷。

## 章纲

每章写四样。

- 这一章谁想要什么。
- 什么挡着。
- 怎么转，或者谁做了什么选择。
- 章末的状态，以及交给下一章的问题。

细化的时候用时间、地点、人物、起因、经过、结果六样把一段情节摊开。摊开的过程里会冒出新的情节，也会发现设定没想全的地方，随手记下来回头补。

也可以顺着成长的阶梯来切章。这张地图里主角要升到哪一档，中间经过哪几小步，每一步靠什么上去，上去之前要铺垫什么。

一章只装一个小目标。章纲里一章写了三件大事，写的时候就会被压成概述。

章纲旁边标上关联的伏笔编号，埋的标埋，收的标收。

## 节奏

情节的起伏像过山车，落差越大，读者的感受越强。一直平，读者提不起劲。一直高，读者会麻。

起伏之外还有拍子。平稳的情节配慢的拍子，冲击的情节配快的拍子。

排章纲的时候在旁边画一条线，标出哪几章是压，哪几章是放，哪几章是缓。没有特别设计时可以这样排，几章之内给读者一次小的兑现，每卷一次大的高潮，大高潮之后跟一两章缓的。这是默认的排法，按题材和平台调整。

主角长了本事以后，要安排一个场合让这份本事值钱，一个对手，一个难处，一群看着的人。

高潮不在多，放在主线的关口上。所有的手法，节奏、悬念、伏笔、人物，都往那一点上集中。积蓄够用两三次的时候可以连着来，然后一定要收。

## 桥段的几种搭法

| 搭法 | 做法 |
|---|---|
| 对比 | 放一个和主角处处相反的人或处境在旁边，读者有了量尺 |
| 垫高 | 先把一个人写得极强，再让他在另一个人面前低头，后者不必出手就站到了高处 |
| 设陷 | 一路把主角逼向绝境，然后翻转。低谷拖得住，翻转要快 |
| 先抑后扬 | 想让谁出彩，先压一压他。想让谁垮，先让他威风 |
| 横切 | 从事情的中间切进去，把一个让人纳闷的局面摆在前面，来由倒着讲 |
| 一物两面 | 用一件东西同时照出对立的两边 |
| 明暗双线 | 明里一条线，暗里一条线，在一个场景里撞上 |
| 偶然里的必然 | 开头可以是偶然，往后的每一步都从人物的性情里来 |
| 以小见大 | 题材小、人物少的段落，用一件小东西带出大处境 |
| 串珠 | 几段互不相干的人和事，用同一个处境串起来，各照一面 |
| 平淡里藏着 | 表面没有激烈的冲突，底下有一股情绪在走。这种最难，有把握再用 |

出人意料要落在情理之中。读者没猜到，回头一想又觉得只能如此。读者猜到了也不丢人，不要为了让人猜不到去拧人物。

## 伏笔和悬念

伏笔是先在前面放下的东西，到后面呼应出来。它可以是一个画面、一段戏、一句对白。

四条规矩。

1. 不离主线。和主线无关的伏笔收回来也没有力量。
2. 不贪多。伏笔多了读者分不清，主题也糊了。连贯的一串伏笔可以分段埋，最后拼起来。
3. 收在高潮上。伏笔是藏着的炸药，在转折和高潮的地方引爆。
4. 必须收。埋了几个就要收几个。

埋和收不要隔得太远，读者会忘。隔得远的，中途再碰一下。

每个伏笔在总纲的伏笔表里记一行，编号、内容、埋在哪里、以什么形式、收在哪里、收的条件。编号用 F 加序号，例如 F01。正文开始以后，状态在 `创作记录/未发生待办.md` 里追，沿用同一个编号，埋和收各占一行，写成 `F01-埋`、`F01-收`。

悬念是读者想知道而还不知道的事。读者最想知道的答案不能早给，每过一段透一点。揭开的时机像拉鱼竿，早了鱼没咬稳，晚了饵被吃完。

### 真相与线索表

悬疑、推理和有大反转的书，在总纲里加这张表。它管住三件容易乱的事，真相是什么，谁在什么时候知道，读者在什么时候知道。

| 谜 | 真相 | 故事里谁一开始就知道 | 主角在哪里知道 | 读者在哪里知道 | 线索埋在哪里 | 用什么把读者引开 |
|---|---|---|---|---|---|---|

每个谜至少有两三条读者事先见过的线索。揭开的时候读者回头能找到，才算公平。引开读者的东西也得是真的，只是指错了方向。

主角知道和读者知道可以不同步。读者先知道，戏在于看主角怎么撞上去。主角先知道，戏在于他瞒着什么。

## 支线和多线

支线让故事有血肉，配角的故事、盟友的故事、敌对势力的动向都算。支线可以套用四个阶段。

三条规矩。

- 归得回来。支线最后要回到主线上，回不来的收不了尾。
- 主次分明。支线越写越大，把主线盖住了，是长篇最要当心的事。主角不能长时间不在场。
- 舍得割。主线已经扎实了，就不再往上堆东西。

## 结局

现在定方向，细节等写到最后一卷再定。结局要回答主题那个问题，兑现开篇对读者的承诺。

| 收法 | 说明 |
|---|---|
| 圆满 | 主角达成目标，对手伏法，各人有归宿 |
| 登顶 | 突破最后一级，或者站到世界之巅 |
| 归隐 | 放下权势和纷争，回到平常日子 |
| 开放 | 主角的去向留白。可以省掉最后的结果，不能把他最要紧的那个选择也藏掉 |
| 悲剧 | 主角或重要人物以沉重的代价换来一个阶段的结果 |
| 首尾呼应 | 回到开篇的场景或那件东西上。只有它的含义已经变了，才值得回来 |
| 反转 | 揭开幕后的人或世界的真相，前文的理解被推翻。要早有铺垫 |
| 新的征程 | 旧的危机了结，更大的世界刚刚打开 |
| 群像延续 | 把镜头分给配角和下一代 |
| 余韵 | 大战之后用几段安静的日常收住 |
| 消散 | 主角融进规则或大道，不再以原来的样子存在 |

两种收法要避开。一是一切原来是场梦，读者投入的感情被一笔勾销，除非全书从头就为它铺了路。二是主线没展开就匆匆了结。

最后一个音符最要紧。故事已经让读者感到的东西，不再让叙述者出来说一遍。

## 最后过一遍

章纲排完，在动笔之前问这些。

- 每一段情节有没有吸引力。删掉它，读者会不会觉得少了什么。
- 有没有违反常理、读者接受不了的地方。主角窝囊受气太久的段落，趁早换掉。
- 每个转折用到的东西前面给过没有。
- 讲的顺序是不是最好的。有没有哪一段倒着讲、插着讲、换一个人的眼睛看会更有力。
- 伏笔表里每一条都有收处。
- 主角每升一档，有没有给他用武之地和相称的位置。
- 相邻两卷的对手强度衔接得上。
- 年表里的时间和年龄对得上。

## 大纲会变

大纲不会一次周全。写的过程中发现更好的走向就改，改了当时就更新文件，在文件头部记下版本和改动的原因。

旧版本移到 `大纲/存档/`，文件名带上日期，不和现行版本放在一起。续写时只认现行版本。

已经写成正文的事实不因为改大纲而自动改变。大纲改了以后和已写正文冲突的地方，列出来让用户定，是改正文还是让新大纲迁就已有的事实。

## 完成的样子

模板在 `assets/templates/全书总纲.md` 和 `assets/templates/章纲.md`。

- 总纲里有一句话故事、两三股主线和各自的阶段、主线对照表、分卷表、每一卷五百字左右的分卷纲、年表、伏笔表、结局方向。
- 悬疑、推理和有大反转的书，总纲里有真相与线索表。
- 眼前要写的这一卷有章纲，至少细化到接下来的五到十章，每章四样俱全。
- 最后一遍检查的八个问题都答得上，答案写在总纲末尾的检查一节里，有问题的那几条写明打算怎么改。
- 文件头部写明版本、日期、状态。
