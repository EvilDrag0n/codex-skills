# 项目说明

主题定下来就建这份文件。以后每新增或改动一份文件，回来更新现行文件表。

| 项 | 内容 |
|---|---|
| 书名 | （暂定） |
| 题材 | 主题材，加一两种调味 |
| 读者 | 年龄层、偏好、平台 |
| 计划篇幅 | 总字数，分几卷 |
| 章均字数 | 3000 |
| 人称与视角 | 第三人称，贴近主角 |
| 尺度与禁区 | 用户没提就写“用户未指定” |

## 用户定下的

逐条写用户明确说过的设定、人物、情节、结局和不要的东西。这些是硬约束。

## 暂定的

逐条写为了往下做而自行定下、还没经用户确认的内容。用户确认以后移到上一节。

## 没核准的现实部分

故事里依赖真实历史、城市、职业、法律、医学或技术，而这次没有查证的条目。没有就写“无”。
