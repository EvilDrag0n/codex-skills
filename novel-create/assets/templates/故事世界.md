## 自然环境

## 社会环境

### 看得见听得到的

建筑、陈设、衣食、器物、称谓、口音、节庆。

### 看不见的

谁说了算，钱从哪里来，人信什么，犯了事怎么罚。

|---|---|---|---|---|

## 主角往上走的阶梯

写实题材写这一节，用现实里现成的阶梯，或者写主角离目标有多近。只写主角从哪一档到哪一档，每一档做事的方式有什么不同。

## 力量阶梯

升级流和有超凡力量的题材才要这一节，别的题材删掉。

| 大级 | 名称 | 到这一级能做什么上一级做不到的事 | 全书用处 |
|---|---|---|---|
| 最高 | | | 传说，留白 |
| 高 | | | 出场人物的顶，主角收尾时到这里 |
| 中 | | | 各卷的大对手 |
| 中低 | | | 各卷的小对手 |
| 低 | | | 高出普通人一头 |

小级怎么分，体现的是哪种量的差别。

武力以外的力量，钱、权、名、智，各在谁手里。

## 地图

主角在每一卷里活动的范围。

| 地图 | 对应卷 | 主角进来时的处境 | 这里的对手 | 主角要的东西 | 主角站住以后谁改了态度 | 离开的理由和铺垫处 |
|---|---|---|---|---|---|---|

升级流在“主角进来时的处境”里写等级，在“这里的对手”里写底层、小头目、大头领的等级和数量。相邻两张地图的等级重叠一档，纵向不超过三层，不够用时加同级不同风格的地图。写实题材不排等级。

## 金手指

题材需要才写，不需要就删掉。

- 是什么
- 它在这个世界里是什么位置，和主线什么关系
- 怎么跟着主角一起长
- 拿掉它，主角还剩什么
- 谁知道它，底牌是什么

## 行当的流程和规矩

职业题材才要这一节。一道工序先做什么后做什么，要填哪几张单子，行里人怎么称呼东西，哪一步外行想不到。

## 代价与边界

每种本事的代价和做不到的事。
